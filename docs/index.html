ESP32APRS LoRa (LU6JMF) — Installer

Firmware for LoRa APRS stations (tested target: Heltec WiFi LoRa 32 V3, 915 MHz), based on ESP32APRS_LoRa by nakhonthai. Flashes straight from your browser (Chrome or Edge) with one click. No software to install.

1. Update an existing device (keeps your configuration)

Use this if the device already runs the original firmware or this one. Only the program is replaced; callsign, WiFi, APRS and LoRa settings stay as they are.

Your browser doesn't support Web Serial. Use Google Chrome or Microsoft Edge on a computer. This page needs HTTPS to work (it already is).
Do not tick any "erase" option in the installer dialog when updating.

2. Fresh install (erases everything)

  1. Connect the board to your computer with a USB cable.
  2. Click the button and select the board's serial port.
  3. Wait for the flashing to finish (about 1 minute).
Your browser doesn't support Web Serial. Use Google Chrome or Microsoft Edge on a computer. This page needs HTTPS to work (it already is).
Warning: this erases everything on the device, including WiFi and APRS configuration. After the install, configure it through the device's own web page (it creates its own WiFi network on first boot).

Tip: if the board is not detected, hold BOOT, tap RESET, then release BOOT, and try again.

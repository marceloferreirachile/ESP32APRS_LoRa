AR-LORA · Argentina LORA System — Installer v1.1-lu6jmf

LoRa APRS firmware (iGate, digipeater, tracker) for the Heltec WiFi LoRa 32 V3 and the Heltec Wireless Tracker V1.1 (433 MHz), based on ESP32APRS_LoRa (nakhonthai) with the core of AR-APRS (LU6JMF). Flashes everything in a single click, directly from your browser (Chrome or Edge), no software installation needed.

  1. Screw the 433 MHz antenna on before powering the board (transmitting without an antenna can damage the radio).
  2. Connect the board to your computer via USB cable.
  3. Click the button for your board and select its serial port.
  4. Wait for flashing to finish (~1 minute).
Your browser doesn't support Web Serial. Use Google Chrome or Microsoft Edge on a computer (doesn't work on mobile). This page needs to be served over HTTPS to work (it already is). Check which board you have before installing: each button installs the version built for that board, and the wrong one may not work correctly. If the Wireless Tracker does not show up as a serial port, unplug it, hold its BOOT button (the one that is not RST) while plugging the USB cable back in, then try again.

First access: connect to the WiFi network AR-LORA_AP (no password), open http://192.168.4.1 and log in with admin / admin. The board starts with callsign NOCALL and every mode off: it does not transmit until you configure it. Default radio: 433.775 MHz, SF12, BW 125 kHz, CR 4/5, sync 0x12 (LoRa APRS standard).

Warning: this erases everything currently on the board (including its configuration) and flashes from scratch.

Already running AR-LORA and want to update without USB? See the release notes ("Existing device" section).
